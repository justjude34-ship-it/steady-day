# Steady Day

Calm diabetes logging companion (PWA). **Not a medical device.**

## How to open (important)

Do **not** open the HTML inside a chat preview — buttons will not work there.

1. Download `index.html`
2. Open it in **Chrome** (Android: Downloads → Open with Chrome)
3. Pick Type 1 or Type 2 → Continue
4. You should see the teal path hero on Today

Data stays on your device (localStorage).
